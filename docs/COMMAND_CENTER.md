# Friday 4.0 Command Center

The Command Center is the unified control surface for Friday's 4.0 orchestration core.

## Included
- Core online/status surface
- Memory count
- Chat, Voice and Hey Jarvis entry points
- Memory, Tools and AI provider entry points
- Live AssistantEvent feed
- Compact responsive layout designed for small phones
- Pull-to-refresh for core initialization/status

The screen is intentionally compact so it does not repeat the oversized UI problem from earlier versions.
